OUR IDEA

Learning can be fun.

QuizMaster is an educational trivia website created as a Web Technologies Midterm Project.

The website allows users to explore different quiz categories, answer trivia questions and compare results on a leaderboard.

Our goal was to build a simple, responsive and user-friendly website while applying HTML, CSS, Flexbox, Grid and Bootstrap.
